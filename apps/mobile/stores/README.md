# تطبيق لكل متجر

كل ملف هنا يمثّل تطبيق متجر واحد على نفس السيرفر. الاسم المختصر (`slug`) لازم يطابق اسم المتجر المختصر بلوحة التحكم ← «المتاجر».

| الحقل | المعنى |
|---|---|
| `slug` | اسم المتجر المختصر (نفسه باللوحة) |
| `app_name` | الاسم تحت أيقونة التطبيق |
| `android_package` / `ios_bundle` | معرّف التطبيق بالمتاجر. **لا تغيّره بعد النشر** وإلا ينحسب تطبيق جديد |
| `scheme` | للروابط داخل التطبيق |
| `splash_background` | لون شاشة البداية |
| `icon` (اختياري) | مسار أيقونة 1024×1024، مثل `stores/glow/icon.png` |

اللون والمظهر والشعار والميزات تنقرى من السيرفر وقت التشغيل، فتتغير من اللوحة بدون بناء نسخة جديدة.

**بناء تطبيق متجر:** GitHub ← Actions ← «Android APK» ← Run workflow ← اكتب `slug` المتجر.
